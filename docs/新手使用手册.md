# OpenGantt 新手使用手册

> 欢迎使用 OpenGantt 项目进度管理平台！本手册专为第一次接触本系统的朋友编写。
> 不需要懂任何编程知识，跟着步骤一步步操作即可。
>
> **先认识两个词：**
> - **甘特图**：一种横条形的时间进度图，每个任务画成一根横条，能一眼看出"什么时候开始、什么时候结束、现在做到哪了"。
> - **管理员**：负责维护账号和系统设置的人（通常是部门 IT 或项目负责人），遇到账号问题找他。

## 第一部分：准备与启动

### 情况 A：公司已经部署好了（大多数人的情况）

如果您公司已经把系统安装到了内部服务器，那么**不需要安装任何软件**：

1. 打开电脑上的浏览器（推荐 Chrome 或 Edge）。
2. 在最上方的地址栏输入管理员给您的网址（例如 `http://192.168.1.100`），按回车。
3. 看到登录页面就说明一切就绪，可直接跳到 [第二部分](#第二部分核心功能使用)。

> **提示**：这个系统装在公司内部电脑上，**必须连接公司网络（或公司 Wi-Fi）才能打开**。在家办公时需要先连接公司的虚拟专用网络（VPN，可以理解为"一条通往公司内部的加密通道"），再打开网址。

### 情况 B：管理员在自己电脑上首次启动

适用场景：第一次把系统跑起来看看效果，或安装到办公室的电脑上。

**准备工作**（一次性）：
1. 安装 Python（版本 3.11 或更新，下载地址 python.org，安装时勾选 "Add to PATH"）。
2. 安装 Node.js（版本 18 或更新，下载地址 nodejs.org）。

**启动步骤**：
1. 打开终端窗口（Windows 上叫"命令提示符"，在开始菜单搜索"cmd"即可找到）。
2. 进入项目文件夹，依次输入以下命令（每输完一行按一次回车，等它跑完再输下一行）：

   ```bash
   # 第 1 步：进入前端文件夹，打包界面
   cd frontend
   npm install
   npm run build

   # 第 2 步：进入后端文件夹，安装依赖并启动
   cd ../backend
   python3 -m venv .venv
   ./.venv/bin/pip install -r requirements.txt
   ./.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```

   > Windows 用户注意：第 2 步中的 `./.venv/bin/` 在 Windows 上要换成 `.venv\Scripts\`。

3. 看到 "OpenGantt 启动完成" 字样表示启动成功。
4. 打开浏览器，地址栏输入 `http://127.0.0.1:8000`（127.0.0.1 表示"这台电脑自己"），按回车。

**操作前后的变化**：
- 启动前：终端不断滚动文字；浏览器打开地址会提示"无法访问"。
- 启动后：浏览器出现 OpenGantt 登录页面，中间有用户名、密码输入框和"登录"按钮。

**首次启动自动创建的账号**（登录后请立即修改密码）：

| 账号 | 初始密码 | 身份 |
|------|---------|------|
| admin | admin123 | 管理员 |
| zhangsan | 123456 | 部门主管 |
| lisi | 123456 | 普通员工 |
| wangwu | 123456 | 普通员工 |

> 更正式的长期部署（装到公司服务器、开机自启）不在本手册范围内，管理员请参阅项目里的《目标机部署指南》或 DEPLOY.md 文件。

## 第二部分：核心功能使用

### 2.1 登录系统

1. 打开浏览器，输入系统网址，回车。
2. 在"用户名"框输入管理员发给您的账号（如 `zhangsan`）。
3. 在"密码"框输入密码（输入时会显示为圆点，这是正常的安全设计）。
4. 点击"登录"按钮。

**操作前后的变化**：
- 登录前：只有登录框。
- 登录后：进入主页，能看到若干彩色部门卡片和右上角您的名字。首次登录会弹出提示建议修改密码。

**退出登录**：点击右上角自己的名字旁边的退出按钮即可。公共电脑上用完一定要退出！

### 2.2 认识主界面

登录后您会看到：

- **中间的部门卡片**：每个部门一张卡片，上面显示这个部门有多少人、多少项目、多少任务。**点击卡片**就进入该部门的页面。
- **右上角工具区**（从左到右）：
  - 「＋ 新建项目」：创建新项目；
  - 「📋 我的工作日志」：查看和填写自己的每日工作日志；
  - 您的名字 + **工作状态**选择器（在岗/请假/休假/出差）；
  - 「修改密码」；
  - 「管理后台」（只有管理员能看到这个入口）。

**三种身份，权限不同**：
| 身份 | 能做什么 |
|------|---------|
| 普通员工 | 看到自己负责的项目；管理自己负责的任务；挑选负责人时**只能选本部门同事** |
| 部门主管 | 部门内所有项目都能编辑；挑选负责人不限部门 |
| 管理员 | 一切权限，另加后台管理 |

### 2.3 查看项目与任务

1. 在主页点击您所在的部门卡片。
2. 进入部门页后，默认在"项目概览"页签，中间列出该部门的所有项目，**点击某个项目**即可打开。
3. 打开项目后，页面上方有三个页签：
   - **任务与进度**：左侧是任务表格（每行一个任务），右侧/下方是甘特图；
   - **每日任务**：见 2.6 节；
   - 项目进度记录与文档也在任务页签的折叠区里。
4. **看甘特图**：点击"甘特图"区域，可用顶部的"日/周/月/年"按钮切换显示范围；点"回到今天"快速跳到今天。
5. **快速筛选**：表格上方的"全部 / 我的任务 / 本周到期 / 已逾期 / 停滞"按钮，可一键筛出您关心的任务。

**操作前后的变化**：
- 点击项目前：只有一列项目名称。
- 点击后：出现任务表格和彩色甘特图，每根横条代表一个任务，颜色和图标表示状态（🟢 正常 / 🟡 需关注 / 🔴 已停滞）。

> **小贴士**：任务表格每行最左边有一个 ▶ 小箭头，点击可以展开这一行，看到更多编辑项（见 2.5 节）。

### 2.4 新建项目与任务

**新建项目**（需要部门主管或管理员权限）：
1. 进入部门页面，点击右上角「＋ 新建项目」。
2. 屏幕中间弹出窗口，填写：项目名称（必填）、项目描述（简单说明做什么）。
3. 点击"创建"。
4. 弹窗关闭，项目列表里立刻出现新项目。

**新建任务**：
1. 打开要加任务的项目，点击右上角「＋ 新增任务」。
2. 在弹出的窗口中依次填写：
   - **任务名称**：例如"编写需求文档"；
   - **开始日期 / 结束日期**：点击输入框会弹出日历，点选日期即可；
   - **负责人**：在名单中**勾选**一位或多位同事（普通员工只能看到本部门同事；被选中的同事名字前会出现对勾）；
   - **前置依赖**：如果这个任务必须等其他任务做完才能开始，就勾选那些任务（可多选，也可不选）。
3. 点击"创建"。

**操作前后的变化**：
- 创建前：任务表格里没有这一行。
- 创建后：表格新增一行，甘特图上同时多出一根横条。如果设置了依赖，甘特图上会画出连线。

### 2.5 修改任务进度和填写说明

1. 在任务表格中找到您的任务（可点"我的任务"快速筛选）。
2. 直接在"进度"一栏的下拉框选择新的完成百分比（0%~100%）。
3. 点击该行最左侧的 **▶ 箭头展开**这一行，会看到：
   - **开始/结束日期**：可修改；
   - **我的进度说明**：用一句话记录今天做了什么，例如"完成初稿，等待王经理审核"；
   - **依赖**：前置任务编号。
4. 在说明框输入文字后，**点击页面其他任意位置**（或按回车），修改会自动保存。
5. 把进度改成 100% 时，任务会被标记为已完成，从"次日待办"中消失。

**操作前后的变化**：
- 修改前：进度显示旧数字，甘特图横条较短。
- 修改后：数字立即更新，甘特图横条同步变长；说明文字会自动进入当天的工作日志。

**重要——关于"说明"的隐私规则**：
- 您填的进度说明和每日任务说明是**按人独立**的：多人负责同一任务时，各自填各自的，互相覆盖不了、也**看不到对方填的内容**。
- 您在工作日志里看到的说明，永远只是您自己写的。

### 2.6 每日任务（每天都要做的事）

适合记录每天重复的工作，例如"晨会""发日报"。它不用每天重建，建一次每天都会出现。

1. 进入部门页，点击顶部「📋 每日任务」页签。
2. **添加**：在最上方的输入框输入任务名（如"晨会"），点击「＋ 添加」。新任务出现在表格中。
3. **分配负责人**（可选，可多人）：点击"负责人"一栏里显示的名字，弹出勾选面板，勾选后点"确定"。
4. **填写"我的说明"**：在"我的说明"一栏点击输入，写今天关于这件事的说明（各负责人独立，互不可见）。
5. **完成打卡**：今天做完了，勾选最右边"今日完成"一栏的方框。
6. **删除**：只有负责人或管理员能删，点行末 ✕ 并确认。

**操作前后的变化**：
- 勾选"今日完成"前：方框是空的。
- 勾选后：方框出现对勾；这条任务会自动写进您今天的工作日志"今日完成"一栏。
- **第二天打开，对勾自动清空**——这是正常设计，表示"今天的还没做"，任务本身不会丢。

### 2.7 我的工作日志

系统每天自动为您整理一份工作日志，平时只需补充两处文字。

1. 点击右上角「📋 我的工作日志」。
2. 屏幕中间弹出大窗口，内容分六段：一、今日完成 / 二、进行中 / 三、阻塞需协调 / 四、关键决策 / 五、补充事项 / 六、次日待办。前两段由系统根据您的任务进度自动生成。
3. **填写"四、关键决策"**：在窗口下方的第一个文字框里，每行写一条今天拍板的重要决定（如"确定采用新方案"），写完点「保存关键决策」。
4. **填写"五、补充事项"**：在第二个文字框里记录当天临时发生的事（如"今天张总找我开会"），每行一条，写完点「保存补充事项」。
5. 保存后窗口上方的日志文字会立即更新，看到自己刚写的内容出现在对应段落里。
6. 需要把日志发给他人时点「复制全文」，然后到聊天窗口粘贴即可。

**操作前后的变化**：
- 填写前：日志的"五、补充事项"一栏显示"（无。可在「我的工作日志」弹窗中记录当日临时事项）"。
- 保存后：这一栏列出您写的条目。

> 每天下午 **17:30** 系统会自动把当天的日志存档（之后修改进度不影响已存档内容；当天写的会照常保存）。若管理员配置了企业微信群通知，同时间会在群里收到当日工作简报。

### 2.8 上传和下载项目文档

周报、验收单等文件可以挂在项目下，团队随时取用。

**上传**：
1. 打开项目，在"任务与进度"页签下找到「项目进度文档」区域，点击展开。
2. 点击"选择文件"，在弹出的文件窗口中选中要上传的文件（单个不超过 20MB）。
3. 可填写一句备注（如"3 月第一周周报"），然后点"上传"。
4. 文件名出现在文档列表中，并显示上传人和时间。

**下载**：在文档列表中点击文件名旁的下载按钮，文件会保存到浏览器默认的"下载"文件夹。

### 2.9 设置自己的工作状态

请假或出差时，把状态改一下，管理员统计日报时会自动把您排除在外。

1. 点击右上角自己名字旁边的状态显示（默认显示"在岗"）。
2. 在下拉列表中选择：在岗 / 请假 / 休假 / 出差。
3. 页面弹出提示"工作状态已设为：××"即生效。

### 2.10 修改自己的密码

1. 点击右上角「修改密码」。
2. 弹窗中依次输入：原密码 → 新密码（至少 6 位）→ 再输一遍新密码确认。
3. 点击"保存"。提示成功后，下次登录请使用新密码。

### 2.11 管理员专属：后台管理

管理员登录后，右上角会多一个「管理后台」入口（地址是网址加 `/admin`），常用操作：

**给新同事开账号**：
1. 进入管理后台，找到"账号管理"。
2. 点击"新增账号"，填写：用户名（建议用拼音，如 `zhaoliu`）、初始密码（至少 6 位）、姓名、角色（普通员工/部门主管/管理员）、所属部门（可多选）。
3. 保存后把账号和密码告诉同事，并提醒首次登录修改密码。

**其他常用**：
- **重置密码**：同事忘记密码时，在账号列表找到他，点"重置密码"，设置一个临时密码告诉他。
- **停用账号**：同事离职时停用（不建议直接删除，历史记录会找不到人）。
- **部门管理**：新增/改名部门。
- **查看操作日志**：系统自动记录谁在什么时候改了什么，方便追溯。

## 第三部分：常见问题解答

**Q1：打开网址提示"无法访问此网站"？**
- 检查是否连接了公司网络（在家需先连 VPN）；
- 核对网址有没有输错（末尾通常没有多余的空格）；
- 若是自己电脑启动的，确认终端窗口还开着、显示"启动完成"，地址用 `http://127.0.0.1:8000`。

**Q2：忘记密码了怎么办？**
自己无法找回，请联系管理员在后台"重置密码"，拿到临时密码后登录，再按 2.10 节改成自己的新密码。

**Q3：登录后看不到某些项目？**
这是权限设计：普通员工只能看到**自己负责**的项目，部门主管能看到本部门全部项目。如果确实需要参与某个项目，请联系管理员或部门主管，由他把任务分配给您（您被加为负责人后即可看到并编辑该任务）。

**Q4：为什么我填的任务说明，同事看不到？他的我也看不到？**
这是刻意的隐私设计：**说明按人独立**，每人只看到自己填的内容，互不影响。多人负责同一任务时不会互相覆盖。

**Q5：填完说明好像没保存？**
说明在您"离开输入框"时自动保存。输入完成后，**点击一下页面其他位置或按回车**，看到输入框变回普通状态即已保存。刷新页面后内容还在就说明保存成功了。

**Q6：昨天勾选的每日任务"今日完成"，今天怎么没了？**
正常现象。完成状态按天记录，第二天自动清空，表示"今天的还没做"；任务本身和您填的说明都还在。

**Q7：甘特图上的横条拖不动？**
设计如此——为了避免不小心拖乱排期，甘特图**只用来查看**。所有修改请在左侧任务表格中进行。

**Q8：上传文档失败了？**
单个文件不能超过 20MB。文件太大时，可以先压缩（右键文件 → 压缩），或拆分成多个文件再传。

**Q9：每天下午收到的企业微信简报是什么？**
每天 17:30 系统自动把全员当天进度汇总成一条简报发到企业微信群（需管理员提前配置）。您只要正常更新任务进度、勾选每日任务，简报里就会有您的内容，无需额外操作。

**Q10：浏览器提示"登录已过期"？**
登录状态一段时间不操作会自动失效，**重新登录**即可，之前填写的内容都已保存，不会丢失。
