📋 OpenGantt 新手速用手册

不需要懂电脑技术 · 跟着数字点就行 · 约 5 分钟看完

一、三步开始用

  1. 打开浏览器（推荐 Chrome 或 Edge）
  2. 地址栏输入管理员给的网址（如 192.168.1.100），回车
  3. 输入账号密码，点「登录」
打开不了？必须连接公司网络（在家先连公司 VPN）。忘记密码找管理员重置。

二、每天要做的三件事

1️⃣ 更新任务进度 + 填一句话说明

  1. 点部门卡片 → 点你的项目 → 在任务表格找到你的任务（可点「我的任务」快速筛选）
  2. 在「进度」栏选新的百分比
  3. 点该行最左边的 ▶ 箭头 展开，在「我的进度说明」写一句话（如"完成初稿，等审核"），然后点一下页面其他位置即自动保存
说明按人独立：多人负责同一任务时，各自填各自的，互相看不到、覆盖不了——这是隐私设计。

2️⃣ 打卡每日任务（每天重复的事，如晨会、发日报）

  1. 进部门页 → 点「📋 每日任务」页签
  2. 首次使用：顶部输入框输入名称 → 点「＋ 添加」（建一次，每天自动出现）
  3. 今天做完了：勾选该行「今日完成」方框 → 自动写入今天的工作日志
第二天对勾自动清空是正常的——表示"今天的还没做"，任务和说明都还在。可在「我的说明」栏填写该任务的说明（同样按人独立）。

3️⃣ 补充工作日志（可选，但建议写）

  1. 点右上角「📋 我的工作日志」→ 弹出当天日志
  2. 四、关键决策框：每行写一条今天拍板的事 → 点「保存关键决策」
  3. 五、补充事项框：记录临时发生的事（如"今天张总找我开会"）→ 点「保存补充事项」
完成后点「复制全文」就能把日志发给任何人。每天 17:30 系统自动归档当天日志（配置了企微群的话，群里同时收到简报）。

三、偶尔要用的操作

➕ 新建任务

  1. 打开项目 → 右上角「＋ 新增任务」
  2. 填任务名、起止日期（点日历选）
  3. 勾选负责人（可多人）、需要的话勾前置任务
  4. 点「创建」，甘特图上立即出现新横条

👤 请假 / 出差报备

  1. 点右上角自己的状态（默认"在岗"）
  2. 选：在岗 / 请假 / 休假 / 出差
  3. 统计日报时自动把你排除在外

🔑 修改密码

  1. 右上角「修改密码」
  2. 输原密码 → 新密码（至少 6 位）→ 再确认
  3. 保存后下次登录用新密码

📄 项目文档上传

  1. 项目内展开「项目进度文档」
  2. 选文件（单个 ≤ 20MB）+ 可写备注
  3. 上传后团队成员都能下载

四、三种身份能做什么

身份能看到的挑负责人范围
普通员工自己负责的项目和任务只能选本部门同事
部门主管本部门全部项目（可编辑）不限部门
管理员全部 + 管理后台不限部门

五、常见问题

网页打不开？

先确认连了公司网络（在家先连 VPN）；再核对网址；自己电脑启动的话，确认黑色终端窗口还开着、地址用 127.0.0.1:8000。

忘记密码？

联系管理员在后台「重置密码」，拿临时密码登录后自己再改一个新的。

登录后看不到某些项目？

正常——普通员工只看到自己负责的项目。需要参与时，请主管把相关任务分配给你。

填完说明好像没保存？

说明在"离开输入框"时才保存：输完后点一下页面其他位置或按回车。刷新后内容还在就是保存成功。

昨天勾的"今日完成"，今天怎么没了？

正常。完成状态按天记录，每天自动清零，表示"今天的还没做"；任务和说明不会丢。

甘特图的横条拖不动？

设计如此——防误触。甘特图只用来"看"，所有修改都在左侧任务表格里做。

文档上传失败？

单个文件不能超过 20MB，太大就先压缩或拆分再传。

提示"登录已过期"？

重新登录即可，之前填的内容都已保存，不会丢。
